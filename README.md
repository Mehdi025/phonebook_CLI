# 📞 Phonebook CLI

A simple command-line phonebook application written in Python.

## ✨ Features
- Add, search, delete, and show contacts
- Data stored in a JSON file (`contacts.json`)
- Phone validation (7-15 digits, supports +98 format)
- Persian and English menu support

## 🛠️ Technologies
- Python 3
- JSON (for data storage)
